01
We explore AI for materials. Think of AI image generation — a model turns noise into a structured picture. Could that idea help us design new materials? For crystals, we describe a repeating pattern of atoms — which elements, where they sit, and how the cell repeats. These become the variables that AI learns to generate. But looking like a crystal is only the first step. Would its atoms stay balanced? Would a small disturbance make it change? To find out, we compare fast AI predictions with independent physics calculations. We follow generation, control, and physical testing — how AI builds candidates, whether it follows instructions, and ultimately, can we trust the results?
02
How do we turn an AI-generated structure into a materials candidate worth investigating? We will follow its generation, test how well we can control it, and compare its predictions with physics. First, let us see how to translate a crystal into something a neural network can work with.
03
To generate a crystal, the network needs three ingredients. Element identities tell it what atoms to use. Fractional coordinates say where they sit inside the cell. The lattice tells it how that cell repeats. The highlighted atom connects the picture directly to a row of numbers. Together, these variables describe the whole periodic structure.
04
There is one more thing the network needs — each atom’s surroundings. Because a crystal repeats, a neighbour may sit just outside the box we draw. Here, including periodic copies reveals those neighbours. A graph lets atoms exchange information across these connections. Now the network can use local environments when updating the structure.
05
With that representation in place, we can ask what noise means for a crystal. An element identity can be hidden behind a MASK. A position can be displaced, and the cell can be distorted. Here, we can see these three effects separately. Learning to recover them is the basis of the generation process.
06
During training, the network learns to recover structure from noisy examples. During generation, we start with a noisy state and apply that learned update repeatedly. The network predicts changes to identities, positions and the lattice together. We now understand the recipe. Next, let us watch what happens when we actually run it.
